# ADR 0284 — Context on the canonical operational issue

Maintenance reuses `OperationIssue`, its task/property ancestry and the existing
offline report/photo producer. Append-only context versions attach or detach
original records with native source fingerprints, actor-bound nonce receipts,
negative closure and same-transaction audit/outbox evidence.

Each original source authorizes its own labels and documents. Operational issue
access does not grant financial or personal access. Unavailable links remain
masked; native context history checks source authority before exposing reasons.
General audit views mask context details. An actor may confirm only their own
command outcome without receiving a private linked source body.

Private response composition checks permission/grant-transition stamps, and the
interface clears private data before revalidation, offline and visibility changes.
No money, expense, stock or duplicate issue engine is introduced. Asset references
remain unavailable until F-AST-01 supplies its real native register and adapter.
