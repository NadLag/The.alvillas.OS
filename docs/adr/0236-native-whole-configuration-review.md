# Native whole-configuration Review

F-ONB-03 validates the complete current Property configuration after all nine native configuration steps. Earlier step envelopes remain immutable historical evidence. A whole Review reads current canonical sources and pins them to its review fingerprint; it does not substitute historical captures for current settings or rewrite earlier records.

Every source must pass held and stored authority checks before private values are loaded, including independent financial source access. Current Property geography, explicit Owner ownership, Team identities, source rules, templates and binding revisions remain part of the metadata boundary. A second check after audit and before admission prevents stale review from becoming accepted configuration.

Structural validation covers all nine configuration families. Organization-configured required fields and existing Team/channel/catalog minimums remain in `config_rule`. Missing or invalid configuration produces blocking issue codes. Whole Review does not activate a Property, run operations, alter money, assert legal acceptance or contact providers. Activation, owner package, bilingual delivery and readiness retain their separate approved features and restrictions.
