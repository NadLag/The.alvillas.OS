# Native whole-configuration Review

F-ONB-03 validates the complete current Property configuration after all nine native configuration steps. Earlier step envelopes remain immutable historical evidence. A whole Review reads current canonical sources and pins them to its review fingerprint; it does not substitute historical captures for current settings or rewrite earlier records.

Every source must pass held and stored authority checks before private values are loaded, including independent financial source access. Current Property geography, explicit Owner ownership, Team identities, source rules, templates and binding revisions remain part of the metadata boundary. A second check after audit and before admission prevents stale review from becoming accepted configuration.

Structural validation covers all nine configuration families. Organization-configured required fields and existing Team/channel/catalog minimums remain in `config_rule`. Missing or invalid configuration produces blocking issue codes. Whole Review does not activate a Property, run operations, alter money, assert legal acceptance or contact providers. Activation, owner package, bilingual delivery and readiness retain their separate approved features and restrictions.

Workflow conditions also depend on current referenced configuration. Resolve only registered exact keys through the canonical scope selector, authorize each identity and its independent financial sources before requesting value sizes or values, and reject missing, invalid or inconsistent task references. Preserve original referenced identities in the encrypted whole snapshot so later corrections cannot substitute current values during historical reads or creator-only nonce recovery. The legacy `staff.compensation` key has the same independent compensation authority as the existing namespaced compensation keys.

Whole Review uses a stable JSONB fingerprint for its source metadata and verifies the stored fingerprint before decryption. AEAD binds the complete validation, raw original sources, policy, creator, command nonce, predecessor and recorded source fingerprint. Existing step fingerprint contracts and envelopes remain unchanged. Native birth uses append-only migration 231, explicit manifest shape 232, additive role-binding correction 233, and canonical effective-reference guard 234; already applied migration bytes are immutable. Row locks, deferred native event/audit guards and a final current-source comparison make each accepted Review one atomic tenth native revision.

Live compound compensation references keep the shared independent financial source checks. Historical staff-only audit settings keep their established scoped compensation classification; mixed financial-rule audit rows still require every source. Whole Review does not turn a historical staff amount into a ledger entry or change existing audit export permissions. Browser compilation retains every original input at the application's existing 3 GiB heap allowance as acceptance coverage grows.
