# ADR 0147: Current receivable aging from original posted movements

Date: 2026-11-02

Receivable assignments retain the explicitly chosen debtor and optional civil due date. Aging uses those retained values, the actual database clock, the organization profile's configured timezone and versioned, gapless overdue bands. No payment term or due date is inferred. Unscheduled claims remain separate. Released assignments and exactly reversed original claims are absent from open aging; their immutable history remains available. Fully received claims contribute no open balance. Invalid financial evidence rejects the report rather than being clamped or ignored.

The original receipt calculation now has one set-based implementation. Its existing scalar boundary delegates to the same implementation and retains its exact original amounts, receipt exclusions and financial-history fingerprints. Qualification compares 305 original scalar cases and 219 original assignments across 204 tenant/currency groups, including original corrections, unknown and null identifiers, foreign and unset tenants, duplicate identifiers and empty requests. All original values, row versions and functions survive the qualification rollback. All 51 existing receipt PostgreSQL cases pass against the isolated candidate. A forward migration adds the batch function and changes the scalar wrapper; no existing SQL file or financial row is rewritten.

One MVCC statement returns complete matching bucket totals and a bounded page. All amounts come from the original assigned claim less actual original and opposite ownership postings. The shared Money implementation checks page amounts and aggregate totals; counts remain decimal strings. Private pagination binds the tenant, actor, filters, effective rule identities, current civil date and complete financial-history fingerprint. Changed source evidence or configuration requires a refresh. No historical accounting cutoff is invented by this current view.

Independent unconditional organization authority for receivables, journals and salary sources remains mandatory, intersecting held restrictions with freshly loaded grants. The response reuses the existing presenter and private HTTP boundary. An attributed private-read audit precedes the final authority and configuration checks. Party names are not inferred from current reservations or disclosed through this view. EN/FR and optional AR band labels use the existing localized-content contract.
