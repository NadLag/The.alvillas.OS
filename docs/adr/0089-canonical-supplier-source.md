# 0089 — Canonical supplier source for payables

F-FIN-23 requires a supplier identity before native invoice liabilities and their payment history can be attributed. The approved `supplier` entity does not yet exist. One tenant-scoped source supplies the Finance and later F-SUP-01 directory; no alternate supplier/person catalogue is introduced. Categories are authored data, with no business category list in code. This source does not make supplier payables DONE: invoices, configured allocations/approvals, immutable liability/payment/reversal journals, history and complete acceptance remain required.

Creation uses an organization request key and immutable fingerprint, UUID v7 and the existing per-organization SUP reference sequence. Edits use compare-and-swap versions, attributed audit and archive/restore. Source identity, creator and request facts cannot change; PostgreSQL prevents hard deletion. Supplier contact fields use the central serializer and independent supplier permissions. Complete organization sources share an eligibility helper around the existing authorize evaluator; it retains caller permissions and denies wildcard grants from narrower scope types. The company-ledger check delegates to the same helper with its existing contract.
