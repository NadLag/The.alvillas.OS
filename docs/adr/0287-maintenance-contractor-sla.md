# 0287. Maintenance contractor service targets

Accepted for F-MNT-04.

Contractor assignments reference an authorized supplier and the original Operations task. Each revision retains the priority, effective configuration rule, and response and completion deadlines. Reassignment and removal append revisions. The current SLA uses original task start or completion evidence, with the next assignment or terminal task event closing the previous measurement window.

Property, city, region, and organization configuration scopes use the existing rule resolver.
