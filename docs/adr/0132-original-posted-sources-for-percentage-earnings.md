# ADR 0132 — Original posted sources for percentage earnings

Percentage earnings use actual sealed, unreversed financial postings selected under `staff.compensation_percentage_earnings`. Entered base amounts and replacement scope labels are rejected. Each source retains its actual posting, journal, ledger account, original assignment, effective compensation and configuration identity. A posting may earn compensation for different people, but cannot be counted twice for the same person through overlapping assignments.

Resolve retained journal dimensions against actual tenant property, reservation, task and owner rows. Linked scopes must agree. Original contract scope must cover the actual financial source. Neither arbitrary JSON nor the operational role supplies financial authority. Check the whole original journal amount, each original rate, the whole beneficiary earning and the whole run against both held and fresh authority. Complete source preparation remains internal and performs no writes; public review and durable financial creation must provide their own attributed audit receipts.

Use the existing exact Money percentage calculation and round once over the selected sources for one original assignment. Independently dated bases resolve their own original contract versions. Deterministic identity ordering makes source fingerprints stable; a final recheck rejects changes to authority, policy or original source facts. SQL independently checks actual effective boundaries and rejects posted instants that JavaScript cannot represent exactly. A financial run must retain typed foreign keys and enforce source uniqueness and original journal reversal checks at the database boundary before financial creation is exposed.
