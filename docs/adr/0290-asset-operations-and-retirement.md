# ADR 0290. Asset operations and retirement

Preventive schedules use versioned Operations series and existing checklist templates. The reserved series key identifies the canonical asset. Generation verifies the organization, property and retirement state before creating native tasks.

Replacement and disposal append auditable lifecycle events. A replacement must be an existing asset at the same property. Retiring an asset ends future preventive task generation and warranty alerts. Existing tasks, Maintenance links, accounting and asset history retain their original records.
