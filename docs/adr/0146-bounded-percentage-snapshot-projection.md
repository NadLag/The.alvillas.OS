# ADR 0146: Bounded original percentage snapshot projection

Date: 2026-11-02

The 500-property admission gate measures the authenticated HTTP path and requires p95 below 2,000 ms. PostgreSQL independently verifies all original posted-income witnesses, their exact same-currency journal amounts, effective contracts, tenant scope, snapshot values and same-birth financial history. These checks remain required for requests and worker-created runs.

The validator previously extracted the complete retained JSON witness array again for every witness position. It now materializes the array once and joins each original position to its exact retained value. The final equality check and every financial, temporal and authorization condition are retained. A left join preserves missing-slot rejection. The per-row witness birth guard also selects only the source and header scalar fields that its unchanged checks actually read; source locks, worker-receipt rejection and database timestamps remain intact.

The change is an additive forward migration. Existing SQL files, financial rows, invoker security, search paths and function-scoped planning settings are preserved. Qualification uses the actual 500-property portfolio, complete original Money and posting evidence, malformed and foreign source cases, original-actor recovery, the shared worker and a complete populated predecessor restore. HTTP acceptance retains the original threshold and zero browser retries.

The isolated financial journey supplies its required organization timezone explicitly. Its earlier missing-profile rejection remains diagnostic evidence; production still rejects company claims without that setting. Both complete browser profiles retain independent approval, recognition, correction and worker replay, with no financial movements during admission or private reads.
