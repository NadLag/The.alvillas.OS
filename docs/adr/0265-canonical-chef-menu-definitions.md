# ADR 0265 — Chef menus are canonical service definitions

Status: accepted technical implementation for F-SVC-04. Scope unchanged: all 355 features remain required.

Chef definitions extend `services.pricing` order terms. The existing publisher remains the single writer, with reviewed effective financial sources, actual person-provider selection, property availability, audit, immutable version history and nonce recovery. There is no second menu catalog, pricing engine or compensation ledger. Names, descriptions, ingredient/unit labels, preparation and declared allergens require EN, FR and AR. Recipe quantities are positive decimal strings; servings describe one priced unit of the existing pricing model. Recipe payload bytes also bound the existing cursor pages.

The original order already seals its entire `order_terms` against the exact catalog version in PostgreSQL. This retains original ingredients and preparation after menu edits without adding another snapshot store. Cooking confirmation requires a native CHEF task; fulfillment and new financial recognition require actual completion by the originally selected person. A forward migration adds these checks without rewriting historical orders, migrations, allocations, journals or balances. The original sealed financial reversal path remains available.

An operational task endpoint projects only recipe fields from the immutable snapshot in SQL, after independently checking held and current task authority. It serves assigned chefs without access to catalog originals, internal costs, guest identities, tax rules or allocation amounts. Visibility/offline changes discard the displayed online recipe. Field pull optionally projects recipes in one tenant-scoped batch after held and current task authorization, with a final authority recheck. Assigned and supervised field views use the existing actor-bound IndexedDB cache, revision and tombstone handling; recipes survive offline cold reload without caching financial terms or adding a second store. Guest-menu capability exposure remains F-GST-09; requirements/shopping lists, chef compensation orchestration, groceries and transfers remain required F-SVC-05–08 work over the same services.
